# 映视

Android TV 上的影视聚合播放器，包名 `com.cloudreel.tv`。当前版本 **0.2.14**。

界面按横屏电视来排，遥控器可以操作，屏幕点击也可以用。首页、搜索、直播、网盘、收藏、历史、数据源、推送和设置都在左侧导航里。

## 功能

- **首页**：海报墙。顶部是当前焦点的大海报，下面是继续观看、热播榜、电影、电视剧、综艺等横滑货架。筛选只用节目自身的类型、年份、影片类型和评分，不显示线路名。片单来自各源并行聚合后的节目缓存，播放地址在打开详情时再取。
- **数据源**：可以添加 TVBox 单源或多仓地址。多仓会按线路分开保存。配置里的注释、尾逗号，以及图片包裹的配置都能解开。
- **详情和播放**：支持多条播放线路、选集和断点续播。地址属于 115、夸克、阿里云盘或百度网盘时，线路上会标出网盘名称，以及这个网盘是否已经登录。
- **网盘**：115、夸克、阿里云盘、百度网盘都在「网盘」页扫码登录。登录信息只加密保存在本机，用你自己的账号去解析分享或提取码，再交给播放器。
- **直播**：已保存线路里的直播列表会自动带进来。打开直播页时会抽查地址，确认打不开的源会删掉。同一个频道有多个地址时，失败会换下一个。
- **搜索、收藏、历史**：可以跨已启用的源搜索，收藏片子，并从上次进度继续播放。
- **推送**：手机和电视在同一个局域网时，可以用推送页把地址提交到电视。

## 环境

- JDK 17
- Android SDK，`compileSdk` / `targetSdk` 为 35，`minSdk` 为 23
- 已包含 Gradle Wrapper（Gradle 8.13）
- 云端编译可执行 `.cursor/install.sh`，安装 JDK 17 和 Android SDK 35

## 构建

```bash
./gradlew :app:assembleDebug
```

Windows：

```bat
gradlew.bat :app:assembleDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。

单元测试：

```bash
./gradlew :app:testDebugUnitTest
```

## 目录

| 路径 | 内容 |
|---|---|
| `app/src/main/java/com/cloudreel/tv/feature` | 首页、详情、播放、直播、网盘、数据源等界面 |
| `app/src/main/java/com/cloudreel/tv/core` | 配置解析、采集、直播、网盘和播放相关逻辑 |
| `app/src/main/java/com/cloudreel/tv/data` | 数据源导入和本地仓库 |
| `app/src/test` | 解析和线路判断的单元测试 |

## 说明

播放地址来自你自己添加的接口，或应用里的公开测试片。程序不内置网盘账号，也不执行远程下发的 jar。脚本源只能访问网络，不能读写本机文件。
