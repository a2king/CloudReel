# 映视

Android TV 上的影视聚合播放器，包名 `com.cloudreel.tv`。当前版本 **0.2.14**。

电视保持左侧导航，手机用底部的「首页 / 直播 / 搜索 / 我的」。遥控器可以操作，屏幕点击也可以用。

## 功能

- **首页**：海报墙。顶部是当前焦点的大海报，下面是继续观看、热播榜、电影、电视剧、综艺等横滑货架。筛选只用节目自身的类型、年份、影片类型和评分，不显示线路名。继续观看在筛选后仍按最近播放排序，只留下符合条件的节目。片单来自各源并行聚合后的节目缓存，播放地址在打开详情时再取。
- **数据源**：可以添加 TVBox 单源或多仓地址。多仓会按线路分开保存。配置里的注释、尾逗号，以及图片包裹的配置都能解开。
- **详情和播放**：支持多条播放线路、选集和断点续播。地址属于 115、夸克、阿里云盘或百度网盘时，线路上会标出网盘名称，以及这个网盘是否已经登录。当前地址打不开时，会自动换下一条已经有播放地址的源。
- **网盘**：115、夸克、阿里云盘、百度网盘都在「网盘」页扫码登录。登录信息只加密保存在本机，用你自己的账号去解析分享或提取码，再交给播放器。
- **直播**：已保存线路里的直播列表会自动带进来。打开直播页时会抽查地址，确认打不开的源会删掉。遥控器上下键在同一分类里换台，确定键打开分类和频道浮层。同一个频道有多个地址时，失败会换下一个。有节目单提示时会显示一行简要信息。
- **搜索、收藏、历史**：可以跨已启用的源搜索，收藏片子，并从上次进度继续播放。
- **推送**：手机和电视在同一个局域网时，可以用推送页把地址提交到电视。

## 环境

- JDK 17
- Android SDK，`compileSdk` / `targetSdk` 为 35，`minSdk` 为 23
- 已包含 Gradle Wrapper（Gradle 8.13）
- 云端编译可执行 `.cursor/install.sh`，安装 JDK 17 和 Android SDK 35

## 构建

```bash
./gradlew :app:assembleDebug
```

Windows：

```bat
gradlew.bat :app:assembleDebug
```

调试包在 `app/build/outputs/apk/debug/app-debug.apk`。

单元测试：

```bash
./gradlew :app:testDebugUnitTest
```

## 元数据

首页、筛选、排序和榜单只读本地 `shows` 表，不读源站原始标签，也不在列表阶段抓播放地址。

匹配顺序：

1. 条目里如果有 TMDB 编号，节目主键就是 `tmdb:<编号>`。同一编号的多条来源合成一条。
2. 没有编号时，用归一后的标题、年份和节目类型（电影 / 电视剧 / 综艺 / 纪录 / 动漫）生成主键。标题相同、类型相同，且年份要么一致、要么有一边缺失，就视为同一部。
3. 影片类型只保留固定词表（剧情、喜剧、动作、爱情等）。「蓝光」「更新」「HD」「国语」这类站点标签不会变成筛选芯片。
4. 合并时保留更长的标题和简介、更高的评分，海报和背景图用第一条非空地址。

缓存：

- 单个源成功拉到片单后，`sources.last_ok_at` 记为当前时间。6 小时内自动刷新会跳过这个源，界面继续用库里的节目。
- 同一节目在 6 小时内再次被自动写入时，只补海报、背景、简介等空白字段，不覆盖已有内容，也不改 `updated_at`。
- 手动点「刷新片单」，或从搜索结果点进一部片子，会忽略上述 6 小时，重新合并并更新时间。
- 单个源连续失败 3 次后，自动刷新会跳过它，直到手动刷新。单源超时 5 秒。

没有 TMDB Key 时的降级：

- 应用不请求 TMDB。海报、背景和简介只来自片单里已经带上的 `vod_pic`、简介等字段。
- 源站列表没给图时，海报用标题渐变占位，不会为了补图去逐条请求详情或播放地址。
- 没有编号的片子靠标题、年份和类型去重。同名不同年的电影会分开；年份缺失时可能和已有同名节目并到一起。
- 测试源 `https://raw.githubusercontent.com/noimank/tvbox/main/tvboxmuti.json` 本身是多仓索引（`urls`），不是直接的采集站片单。首页会并行跟进一层子配置，跳过脚本和远程 jar，用第一份能返回海报的采集接口拉片单，并把这个接口记在本机。选定接口单独给 90 秒，不占用片单的 5 秒超时；90 秒内没选定就记一次失败。连续失败 3 次后，下次启动会清掉失败计数再试一次。接口已经记下、但片单在 5 秒内没拉完时，下一次刷新直接用记下的接口补海报。

## 说明

播放地址来自你自己添加的接口，或应用里的公开测试片。程序不内置网盘账号，也不执行远程下发的 jar。脚本源只能访问网络，不能读写本机文件。网盘登录仍是本机扫码，不会上传到服务器。电视遥控、直播换台和手机底栏还没有在模拟器里点过，逻辑由单元测试覆盖。
